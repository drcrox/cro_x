# Changelog

Newest first. Each build number matches `## Version` in `CROX/CROX.toc`, the login line in game, and the release on GitHub.

## v0.57 (alpha 2) · cro_x v.57a2
- Horde splash page now uses the orc poster background, with a yellow "Show at login" checkbox in the bottom right corner.
- Alliance screen: the Horde battleground timer logo is locked in above LOK'TAR OGAR, with "You have chosen your faction poorly." underneath.
- The art picker no longer has a splash background choice (the splash and Alliance screens are fixed).

## v0.56 (alpha 2)
- Alliance screen has its own fixed background: the Horde orc glaring back, cropped from the 2005 Blizzard poster (credited).
- The art picker no longer changes the Alliance screen.

## v0.55 (alpha 2)
- `/x bug`: report window that builds a short, paste-ready report (version, game build, last error, recent quiet reasons, last fight).
- Error catcher: one chat line pointing to `/x bug` when cro/x hits an error.
- `/x test`: tells you, in your own chat, why a button press stayed quiet.
- Options > Beta testing: "Report a problem" and "Why was it quiet?" buttons.
- Repo: GitHub bug-report form, Discord thread template, tester checklist, report reader, automatic releases and a daily Discord announcement.

## v0.54 (alpha 2)
- First public build of the alpha 2 rework: engine, two-tab window, splash page, session log and fight review, profanity filter, Credits section, art browser.
