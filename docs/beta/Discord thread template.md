# Discord: bug report thread template

Pin this at the top of the bug-reports channel. Testers copy it, or just paste the output of `/x bug`.

```
**cro/x bug report**
Version: (shown at the top of /x bug)
What happened: (error / awkward line / stayed quiet / too chatty / window / other)

(paste the /x bug report here)

What I was doing:
What I expected:
```

## Pinned instructions (short)

1. In game, type **/x bug**.
2. Pick what happened, add a few words, click **Select all**, press Ctrl+C.
3. Paste it into a new thread here. Nothing is sent for you, and other players' names are already replaced by their class.

Awkward line or odd moment during a fight? Type **/x flag** right after it instead: it lists every line from that fight so you can mark the one that felt wrong.

Press did nothing? Type **/x test** right away. It tells you, in your own chat, why it stayed quiet. Paste that into the thread too.

Need the whole session log? **/x export** gives the full text (long; use a thread attachment or paste in parts).
