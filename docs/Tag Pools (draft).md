# cro.x Alpha 2 — Tag Pools (draft)

Drafted by Claude from **cro.x — Writing Profile**, 2026-11-15. Nothing here is hand-picked yet: all of it is for the beta audit (audit, purge, refine).

## How these pools work
- About 1 line in 3 comes from a tag instead of the baseline pools. Weights: class 20%, drive 15%, homeland 10%, upbringing 10%, spec 10%, professions 10%.
- A tag line can only be said on the archetypes or moments listed after it, and only if its other marks are true (facts rule).
- **Equal options:** every pool has shared lines (all six temperaments) plus one line only each temperament can say, so every temperament gets the same count.
- Ratings [1–5] run light to dark.
- **Profanity filter:** a line with a real swear word shows its clean substitute as *(clean: …)*. The clean line is used while the filter is on (the default).
- No emotes in the tag pools yet; emotes stay a rare accent in the baseline pools.
- Faith appears only in class pools, race-marked homeland lines, and the Faith drive (race-marked there too).

Marks: {in a group}, {on an ally}, {on an enemy}, {after taking damage}, {from stealth}, {pet out}, {beast} (the enemy is a beast), {outdoors}, {race: …}, {fire} and other damage types, {vs Alliance player}.
